SyncVid Build 32 - Changeable Password

Default password: syncvid50

After login:
1. Open Connection status.
2. Press Change password.
3. Enter current password.
4. Enter and confirm the new password.
5. Press Save password.

Important: The password is saved in the browser localStorage. Changing it on one PC does not change it on another browser/device. Clearing site data resets the password to syncvid50.
